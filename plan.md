### 3.3 Scaling Contract: Streaming + Sharding (Hard Contract)

The implementation must support evaluation over extremely large combination spaces (e.g., > 1e13 global combinations) by:

- **Streaming enumeration:** never materialize all combinations in R or C++; decode a combination on-the-fly from a global index.
- **Constant memory in number of combinations:** memory usage is `O(p^2)` per worker thread plus `O(chunk_size)` output buffering,
  independent of the global combination count.
- **Sharding:** `shard_id`/`shard_count` define a deterministic partition of the global index space so that multiple processes can
  run in parallel on different machines without overlap:
  - Each call processes indices `i` in `[combination_start, combination_end)` such that `i % shard_count == shard_id`.
  - Seeding uses the global `i` (Section 6.5), so results are reproducible across shard layouts.

**Index size constraints (hard contract):**
- R uses double-precision numerics for `combination_start`/`combination_end`. For exact integer behavior, require:
  - `combination_start` and `combination_end` are whole numbers (`x == floor(x)`)
  - `0 <= combination_start <= combination_end <= 2^53 - 1` (to avoid IEEE-754 rounding changing indices)
- The C++ backend must be compiled for a 64-bit platform (so global index values like 1e13 are representable as `uint64_t`/`size_t`).

Practical note: writing per-combination CSV output for 1e13+ combinations is usually infeasible due to disk/time; for such runs,
use sharding and/or restrict outputs (e.g., `output = "fit"` only, or add post-hoc filtering/aggregation).

## 4) Output Design

### 4.1 Fit Summary (`*_fit.csv`) — 1 row per combination

| Column | Description |
|--------|-------------|
| `Combination` | Unique identifier string (canonical format below) |
| `X_var`, `Y_var` | Variable names |
| `M_vars` | Semicolon-separated `"M1=varA;M2=varB;...;Mm=varZ"` |
| `m` | Number of mediators |
| `N_complete` | Complete cases |
| `selected_model` | `"Partial"`, `"Semifull"`, or `"Full"` |
| `p_P_vs_SF`, `p_SF_vs_F` | Chi-square difference test p-values |
| `partial_*`, `semifull_*`, `full_*` | Fit measures (chisq, df, p, cfi, tli, rmsea, aic) |

**Canonical `Combination` format (hard contract):**
```
X=<x>|M1=<m1>|M2=<m2>|...|Mm=<mm>|Y=<y>
```
- Ordering is always `X`, then `M1..Mm`, then `Y`.
- Delimiters are literal `|` and `=`.
- Escape rules (URL-style, applied in this order):
  1) `%` → `%25`
  2) `|` → `%7C`
  3) `=` → `%3D`

**Fit indices when `df == 0` (hard contract; matches current m=3 implementation):**
- `chisq = 0`, `pvalue = 1`, `cfi = 1`, `tli = 1`, `rmsea = 0`
- `aic` is still computed from the fitted covariance model (not forced to `NA`).

**CSV numeric formatting (hard contract):**
- Write numeric values with a fixed decimal format (e.g., 6 digits after the decimal) to keep diffs stable.
- Missing values are written as literal `NA`.

### 4.2 Parameter Estimates (`*_params.csv`) — Long format

**Scope (hard contract):** `*_params.csv` contains **only the selected model's** parameter estimates for each combination.
Fit measures for all models are available in `*_fit.csv`.

| Column | Description |
|--------|-------------|
| `Combination` | Links to fit summary |
| `selected_model` | Model these params are from |
| `lhs`, `op`, `rhs` | lavaan-style syntax (`M2 ~ M1`) |
| `label` | Parameter label (`a1`, `d_2_1`, `b2`, `cp`) |
| `est`, `se`, `z`, `p`, `std` | Estimates and inference |

### 4.3 Defined Effects (`*_effects.csv`) — Long format

| Column | Description |
|--------|-------------|
| `Combination` | Links to fit summary |
| `effect` | Effect name (`direct`, `total_indirect`, `adjacent_chain`, etc.) |
| `est`, `se`, `z`, `p`, `std` | Estimates and inference |

### 4.4 Model Selection (Hard Contract)

For each combination, attempt to fit **all three** models (Partial, Semifull, Full). If **any** model fails to fit
(e.g., insufficient complete cases, non-PD covariance, solver failure), treat the combination as **failed**:
- If `write_fit = TRUE`, write a fit row with `selected_model = NA` and all fit statistics/p-values as `NA`
  (except `N_complete` and identifiers if available).
- Do **not** write any params/effects rows for that combination.

When all three models fit, compute nested chi-square difference tests using:

- `p_P_vs_SF`: test Semifull (restricted) vs Partial (less restricted)  
  `chisq_diff = chisq_semifull - chisq_partial`, `df_diff = df_semifull - df_partial` (expected `df_diff = 1`)
- `p_SF_vs_F`: test Full (restricted) vs Semifull (less restricted)  
  `chisq_diff = chisq_full - chisq_semifull`, `df_diff = df_full - df_semifull`

P-values are computed as upper-tail chi-square: `pchisq(chisq_diff, df_diff, lower.tail = FALSE)`.
If `df_diff == 0`, use `p = 1` when `chisq_diff == 0`, else `p = 0` (mirrors current `chisq_pvalue_upper()` behavior).
If `df_diff < 0` or `chisq_diff` is non-finite, set the p-value to `NA`.

**Selection rule (matches current m=3 behavior):**
1. Start at Partial.
2. If `is.na(p_P_vs_SF)` or `p_P_vs_SF < alpha`, keep **Partial**; otherwise choose **Semifull**.
3. If Semifull is chosen, then if `is.na(p_SF_vs_F)` or `p_SF_vs_F < alpha`, keep **Semifull**; otherwise choose **Full**.

Tie-breakers:
- Use `p >= alpha` as “not rejected” (i.e., constraints accepted).
- NA p-values always favor the **less constrained** model.

**Meaning of `alpha` (hard contract):** `alpha` is used **only** for the chi-square difference tests in model selection.
It does not control confidence intervals (no CI columns are produced) and does not change the per-parameter/effect p-values,
which are always reported as two-sided normal-theory p-values from `z = est / se` when `nrep > 0`.

## 5) Statistical Model Generalization

### 5.1 Variable Ordering

`V = (X, M1, M2, ..., Mm, Y)` with `p = m + 2`

### 5.2 Model Specifications

| Model | Equations | df |
|-------|-----------|-----|
| **Partial** | `Mj ~ a_j*X + Σ_{k<j} d_{j,k}*Mk`; `Y ~ cp*X + Σ b_j*Mj` | 0 |
| **Semifull** | Same as Partial, but `cp = 0` | 1 |
| **Full** | `M1 ~ a1*X`; `Mj ~ d_{j,j-1}*M_{j-1}`; `Y ~ b_m*Mm` | `df_full = p(p+1)/2 - (2m+3) = m(m+1)/2` |

### 5.3 Parameter Counts

| Model | Parameter Count |
|-------|-----------------|
| Partial | `p + m(m+1)/2 + m + 1` = coefficients + `p` variances |
| Semifull | Partial - 1 |
| Full | `(m+1) + p` = `(a1, d_{2,1}, ..., d_{m,m-1}, b_m)` + variances = `2m + 3` |

### 5.4 Degrees of Freedom Formula

Let `p = m + 2` and assume (as in the current implementation) a **covariance-only** ML objective with:
- `p(p+1)/2` observed moments (unique covariances)
- Free variances for all variables (`p` variance terms)

Then:
- **Partial** is saturated/just-identified:  
  `npar_partial = p + [m(m+1)/2] + [m+1] = p(p+1)/2` ⇒ `df_partial = 0`
  - `[m(m+1)/2]` comes from `Mj ~ X + M1 + ... + M(j-1)` (sum of 1..m)
  - `[m+1]` comes from `Y ~ X + M1 + ... + Mm`
- **Semifull** fixes `cp = 0`:  
  `df_semifull = 1`
- **Full** (serial chain) has:
  - `m+1` regression coefficients: `a1`, `d_{2,1}..d_{m,m-1}` (m-1), `b_m`
  - `p` variances

So:
```
npar_full = (m+1) + p = (m+1) + (m+2) = 2m + 3
df_full   = p(p+1)/2 - npar_full
         = (m+2)(m+3)/2 - (2m+3)
         = m(m+1)/2
```

Sanity checks:
- m=1: `df_full = 1`
- m=3: `df_full = 6` (matches current fixed-m implementation)

### 5.5 Defined Effects Without Exponential Enumeration

For the **Partial/Semifull** recursive DAG (X → all mediators; earlier mediators → later mediators; all mediators → Y),
the **total effect** of `X` on each mediator and on `Y` can be computed in `O(m^2)` via forward recursion (no path enumeration):

- Total effect of `X` on `M1`:
  - `TE_X_M[1] = a_1`
- For `j = 2..m`:
  - `TE_X_M[j] = a_j + Σ_{k<j} d_{j,k} * TE_X_M[k]`
- Total effect of `X` on `Y`:
  - `TE_X_Y = cp + Σ_{j=1..m} b_j * TE_X_M[j]`

**Effects output contract (stable + testable):**

1) Minimum required effect rows (always present for non-failed combinations):
- `direct`: `cp` for Partial, `0` for Semifull/Full
- `total`: total effect of `X` on `Y` (`TE_X_Y` for Partial/Semifull; for Full this equals `adjacent_chain`)
- `total_indirect`: `total - direct`
- `adjacent_chain`: the *adjacent serial chain only*:  
  `a_1 * Π_{j=2..m} d_{j,j-1} * b_m`

2) Recommended additional effect rows (always present for non-failed combinations):
- `x_to_m<j>_total` for `j = 1..m`: total effect of `X` on mediator stage `Mj` (`TE_X_M[j]`)

3) Optional enumeration (only when `m <= 6` and explicitly enabled):
- Add one effect row per increasing mediator sequence:  
  `ind_X_M<j1>_M<j2>_..._Y` with estimate equal to the product of the corresponding path coefficients.

Interpretation note (hard contract):
- For **Full**, `adjacent_chain` is the **only** indirect path and equals `total`.
- For **Partial/Semifull**, `adjacent_chain` is **one component** of `total_indirect` (do not interpret it as “the” indirect effect).

// Dynamic coefficient storage for arbitrary m
struct DynamicPathCoefs {
    std::vector<double> a;      // a_j for j=1..m (size m)
    std::vector<double> d;      // d_{j,k} for k<j, stored in lower-triangular order
    std::vector<double> b;      // b_j for j=1..m (size m)
    double cp = 0.0;            // direct effect (Partial only)

    // Index helper: d_{j,k} where 1 <= k < j <= m
    // Lower triangular storage (row-major by j): for each j=2..m store k=1..(j-1)
    // Index: (j-1)(j-2)/2 + (k-1) using 1-indexed (j,k)
    double& d_jk(int j, int k) { return d[(j-1)*(j-2)/2 + (k-1)]; }
    double d_jk(int j, int k) const { return d[(j-1)*(j-2)/2 + (k-1)]; }
};

struct DynamicPathFit {
    bool ok = false;
    int n_complete = 0;
    int m = 0;                  // number of mediators

    DynamicPathCoefs coefs;
    double var_x = NA_REAL;
    std::vector<double> var_e;  // residual variances (size m+1: M1..Mm, Y)

    Eigen::MatrixXd sigma;      // (m+2) x (m+2)

    double chisq = NA_REAL;
    int df = NA_INTEGER;
    double pvalue = NA_REAL;
    double cfi = NA_REAL;
    double tli = NA_REAL;
    double rmsea = NA_REAL;
    double aic = NA_REAL;
};

// Worker-local buffers to avoid per-combination allocations
struct WorkerBuffers {
    int p = 0;                           // m + 2
    Eigen::MatrixXd S;                   // p x p sample covariance
    Eigen::MatrixXd sigma;               // p x p model-implied
    Eigen::MatrixXd A;                   // p x p structural coefficients
    Eigen::MatrixXd Omega;               // p x p residual (diagonal)
    Eigen::MatrixXd invM;                // (I-A)^{-1}
    Eigen::VectorXd means;               // p means
    std::vector<double> row_buf;         // p centered values

    // For regression from covariance
    Eigen::MatrixXd Sxx;                 // predictor covariance (max size: p-1 x p-1)
    Eigen::VectorXd Sxy;                 // predictor-outcome covariance
    Eigen::VectorXd beta;                // regression coefficients

    // For Wishart bootstrap
    Eigen::MatrixXd S_rep;               // bootstrap sample cov
    Eigen::MatrixXd L;                   // Cholesky factor
    Eigen::MatrixXd W_A;                 // Bartlett decomposition

    // Online variance accumulators for SE
    std::vector<OnlineVariance> param_vars;   // one per parameter
    std::vector<OnlineVariance> effect_vars;  // one per defined effect

    void resize(int new_m);
};

### 6.4 Combination Enumeration

```cpp
// dims = [nx, nm1, nm2, ..., nmm, ny] (length m+2)
// Decoding: rightmost dimension varies fastest (Y, then Mm, ..., M1, X)

void decode_combination(size_t idx, const std::vector<size_t>& dims,
                        std::vector<size_t>& out) {
    out.resize(dims.size());
    for (int d = dims.size() - 1; d >= 0; --d) {
        out[d] = idx % dims[d];
        idx /= dims[d];
    }
}
```

**Total combination count (C++ safety guard):**
- Compute `total = nx * prod(nm_j) * ny` with overflow checks before casting to `size_t`.
- If the product exceeds `std::numeric_limits<size_t>::max()` (or becomes non-finite if computed as `double`), throw a clear error.
- This guard is required even though R does a preflight check, to avoid undefined behavior when calling C++ directly.

### 6.5 RNG + Bootstrap Determinism (Hard Contract)

To guarantee identical results across `num_threads`, `grain_size`, and `chunk_size`, random number usage must be independent
of scheduling. The backend must use **per-combination RNG seeding**:

- Define a stable global combination index `comb_idx` (0-based) based on the deterministic enumeration order (as produced by `decode_combination()`).
- For each combination, derive a seed:
  - `seed_i = derive_seed(base_seed, comb_idx, 0)` (or an equivalent SplitMix64-style `hash64(base_seed, comb_idx)`)
- Initialize a local RNG per combination: `std::mt19937_64 rng(seed_i)`.
- Consume exactly `nrep` Wishart draws from that RNG for that combination.

Explicitly prohibited:
- Worker-global RNG streams whose consumption depends on task scheduling.

### 6.6 Covariance + Wishart Conventions (Hard Contract)

The refactor must match the legacy m=3 behavior exactly:

- Complete-case covariance `S` is computed with denominator `n_complete - 1` (unbiased sample covariance).
- Wishart bootstrap uses:
  - degrees of freedom `df_wishart = n_complete - 1`
  - Bartlett decomposition to draw `W ~ Wishart(df_wishart, Sigma)`
  - return covariance draw `S_rep = W / df_wishart` so that `E[S_rep] = Sigma`

All fit statistics using `chisq = (n_complete - 1) * F_ml(...)` must use the same `n_complete - 1` factor.

normalize_columns <- function(columns, all_columns, match, m = 2, m_is_missing = FALSE) {
  if (!is.numeric(m) || length(m) != 1 || is.na(m) || m < 1 || m != floor(m)) {
    stop("m must be a positive integer.")
  }
  m <- as.integer(m)

  # Detect legacy format (has m1, m2, m3 but no mediators)
  if (!is.null(columns$m1) && is.null(columns$mediators)) {
    # Convert legacy to new format
    mediators <- list()
    i <- 1
    while (!is.null(columns[[paste0("m", i)]])) {
      mediators[[paste0("m", i)]] <- columns[[paste0("m", i)]]
      i <- i + 1
    }
    m_inferred <- length(mediators)
    if (!m_is_missing && m != m_inferred) {
      stop(sprintf("m=%d does not match legacy columns (inferred m=%d from m1..mK).", m, m_inferred))
    }
    m <- m_inferred
    columns <- list(x = columns$x, mediators = mediators, y = columns$y)
  }

  # Convenience: shared mediator pool -> expand to m stages (default m=2)
  if (!is.null(columns$mediators) && is.character(columns$mediators)) {
    mediators <- replicate(m, columns$mediators, simplify = FALSE)
    names(mediators) <- paste0("m", seq_len(m))
    columns$mediators <- mediators
  }

  # If stages are explicitly listed, infer m from the list length unless user explicitly set m.
  if (!is.null(columns$mediators) && is.list(columns$mediators)) {
    m_inferred <- length(columns$mediators)
    if (m_inferred < 1) stop("At least one mediator stage required.")
    if (!m_is_missing && m != m_inferred) {
      stop(sprintf("m=%d does not match columns$mediators length=%d.", m, m_inferred))
    }
    m <- m_inferred
  }

  # Validate structure
  stopifnot(!is.null(columns$x), !is.null(columns$mediators), !is.null(columns$y))

### 7.2 Output File Management

```r
derive_output_files <- function(output_dir, output_prefix) {
  list(
    fit = file.path(output_dir, paste0(output_prefix, "_fit.csv")),
    params = file.path(output_dir, paste0(output_prefix, "_params.csv")),
    effects = file.path(output_dir, paste0(output_prefix, "_effects.csv"))
  )
}
```

**File creation + overwrite behavior (hard contract):**
- The user-facing `output` argument controls which files are produced. Files not selected must **not be created**.
- If `overwrite = FALSE` and **any** selected output file already exists, stop **before** calling into C++ (no partial outputs).
- If `overwrite = TRUE`, truncate and rewrite the selected files.
- If `output` excludes a file, it is treated the same as `write_* = FALSE` (do not create/open it).

### 7.3 Combination Count Guard (Hard Contract)

Before calling into C++, do a preflight using resolved column sets:

- Let `dims = c(nx, nm1, nm2, ..., nmm, ny)` (length `m+2`).
- Compute `global_total = nx * prod(nm_j) * ny` using `double` (detect overflow to `Inf`).
- Apply the requested range and sharding (`combination_start`, `combination_end`, `shard_id`, `shard_count`) to compute
  `n_to_process` for **this call** (also using `double` with overflow checks).
- Compute `n_to_process` via integer math on **whole-number** inputs (see Section 3.3), for example:
  - `end <- if (is.null(combination_end)) global_total else combination_end`
  - `first <- smallest i >= start with i %% shard_count == shard_id`
  - `n_to_process <- if (first >= end) 0 else 1 + floor((end - 1 - first) / shard_count)`
- If `n_to_process > warn_combinations`, emit a warning with `global_total`, `n_to_process`, and the per-dimension sizes.
- If `n_to_process > max_combinations`, stop with an error **unless** `max_combinations` is `Inf`.

This guard is especially important when `columns$mediators` is provided as a shared pool and expanded across stages.

## Appendix A: Current vs Generalized Parameter Labeling

### Current (m=3)
```
Coefficients: a1, a2, a3, d21, d31, d32, b1, b2, b3, cp
Variances: var_x, var_e1, var_e2, var_e3, var_e4
```

### Generalized (m mediators)
```
Coefficients:
  a_1, a_2, ..., a_m           (X → Mj, j=1..m) [Partial/Semifull; Full constrains a_2..a_m = 0]
  d_{j,k} for k < j            (Mk → Mj) [m(m-1)/2 coefficients, Partial/Semifull; only d_{j,j-1} for Full]
  b_1, b_2, ..., b_m           (Mj → Y) [m coefficients, Partial/Semifull; only b_m for Full]
  cp                           (X → Y) [1 coefficient, Partial only]

Variances:
  var_x                        (X variance) [1]
  var_e_1, ..., var_e_m        (Mj residual variances) [m]
  var_e_y                      (Y residual variance) [1]

Total: m + m(m-1)/2 + m + 1 + 1 + m + 1 = m(m+5)/2 + 3 (Partial)
```
